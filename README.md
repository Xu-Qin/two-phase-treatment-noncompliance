# Two-phase Treatment with Noncompliance

This repository contains the R code accompanying the paper:

**Two-Phase Treatment with Noncompliance: Identifying the Cumulative Average Treatment Effect via Multisite Instrumental Variables**

## Files

- `01_real_data_analysis.R`  
  Reproduces the empirical analyses presented in the paper.

- `02_simulations.R`  
  Reproduces the simulation study presented in the paper.

## Reproducibility

To reproduce the simulation results:

```r
source("02_simulations.R")
```

To reproduce the empirical analyses:

```r
source("01_real_data_analysis.R")
```
